⚙ Settings & Google Sheets Setup

📋 How to set up Google Sheets sync →
One-time Setup (5 minutes):
1. Open sheets.google.com → Create a new spreadsheet → note its ID from the URL
2. In that sheet: Extensions → Apps Script
3. Delete any existing code; paste the contents of Code.gs (provided alongside this app)
4. Click ⚙ Project Settings → Script Properties → Add property:
  SPREADSHEET_ID = your spreadsheet ID
5. Run initializeSheets() once (click ▶ Run in Apps Script)
6. Deploy → New Deployment → Web App
  Execute as: Me | Who has access: Anyone
7. Copy the Web App URL → paste above → Save → click "⟳ Sync Sheets"
