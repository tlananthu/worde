Custom Dialect Rules

        
      

      

        

          1. Styling: <invisible> / <indirect>
          
Use <invisible for="selector"> or <indirect for="selector"> instead of <style>.

        

        

          2. Tables: <t> ... </t>
          
Use <t> instead of <table>. Standard <tr>, <th>, <td> work inside.

        

        

          3. Line breaks: <br>
          
Clean lean line break without closing slash.

        

        

          4. Vertical Rules: <vr> and <vr="name">
          
Default: <vr> (1px width, 50px height, #000). Customize with width, length/height, color.

          
Name rule: <vr="myDivider" length="80px" color="blue"> can be styled via <invisible for="#myDivider">.
