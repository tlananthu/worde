Custom HTML Dialect Specification

1. Invisible & Indirect Styling Tags

Instead of standard <style>, styles are declared through <invisible> or <indirect>. You can target selectors directly using the for="..." attribute, or pass global CSS rules inside. 

<invisible for="h1">
  color: #38bdf8;
  font-weight: 700;
</invisible>

<indirect for=".card">
  border-radius: 12px;
  background: #f8fafc;
</indirect>

2. Table Tag Alias (<t>)

Instead of writing <table>...</table>, the dialect uses succinct <t>...</t> tags. It preserves all native table contents (<tr>, <td>, <th>). 

<t border="1" class="custom-table">
  <tr>
    <th>Item</th>
    <th>Status</th>
  </tr>
  <tr>
    <td>Engine</td>
    <td>Active</td>
  </tr>
</t>

3. Lean Line Break

Write clean <br> instead of self-closing XML-like <br/> or <br />.

4. Vertical Lines (<vr>) & Named Anchors (<vr="name">)

Vertical rules can be declared with custom thickness, length, and color (defaults to 1px width, 50px length, and black color):

  • Standard attributes: <vr width="3px" length="80px" color="#3b82f6">
  • Default line: <vr>
  • Named Rule Anchors: <vr="divider_main"> or <vr="header-line" length="50px" color="#f43f5e">. You can write custom invisible styles for this specific spot via <invisible for="#divider_main">!
<!-- Inline vertical line -->
<vr width="2px" length="60px" color="#64748b">

<!-- Named vertical line anchored at specific spot -->
<vr="customSeparator" length="120px" color="red">

<invisible for="#customSeparator">
  box-shadow: 0 0 10px #ec4899;
</invisible>
